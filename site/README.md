# JAutomata learning site

This is the presentation and build layer for the canonical Markdown in `../docs/`.
Do not edit `src/content/docs/`: `npm run prepare-content` recreates it from `docs/`
before development, checks, and production builds.

## Requirements

Use Node `26.7.0` (recorded in `.node-version`) and npm 11 or later. The
generated-reference freshness gate also requires [uv](https://docs.astral.sh/uv/)
and the repository's Python project environment; it does not add a Python runtime
dependency to `jautomata` itself.

## Run locally

1. From this directory, run `PUPPETEER_SKIP_DOWNLOAD=true npm ci`.
2. Run `npm run dev` and open the local address Astro prints.

Development serves the committed static diagram assets. Before checks or a
production build, install the pinned Chromium used by both the local diagram
renderer and Playwright:

~~~sh
npm exec playwright install chromium
npm run test:diagrams
npm run check
npm run build
npm run preview
~~~

On Linux, use `npm exec playwright install --with-deps chromium` when browser
system libraries are absent. `PUPPETEER_SKIP_DOWNLOAD=true` avoids a second browser
download. If you choose a custom `PLAYWRIGHT_BROWSERS_PATH`, use the same value
during installation and all rendering, checks, builds, and browser tests. See the
[canonical diagram guide](../.omm/README.md) for source editing, regeneration,
exact freshness checks, and the optional local OMM viewer.

## Verify the built site

After `npm run build`, run the browser and static-output checks:

~~~sh
npm run test:e2e
npm run test:links
~~~

`test:e2e` starts a production preview of `dist/` by default, so Pagefind, the
`/JAutomata/` base path, generated content, and production assets are covered.
To smoke-test a published site instead, provide its complete subpath URL:

~~~sh
PLAYWRIGHT_BASE_URL=https://cri5castro.github.io/JAutomata/ npm run test:e2e
~~~

The checks include targeted automated axe scans, not a claim of complete WCAG
conformance. They are supplemented by recorded keyboard, responsive, no-JavaScript,
and motion-preference checks in the milestone verification report.

The production site is configured for `https://cri5castro.github.io/JAutomata/`.
Starlight provides theme switching, keyboard-accessible navigation, and local search.
The focus-view and trace controls enhance the static lessons; the explanatory text,
diagram descriptions, and tables stay readable when JavaScript is unavailable.

## Teaching traces

`src/data/traces.json` is generated by
`../python/scripts/generate_teaching_traces.py` from the Python automata model.
It is not an implementation of the regex engine: browser code displays the emitted
steps only. `npm run check-generated` fails when either traces or the generated API
reference are stale. From the repository root, regenerate both before reviewing a
contract/docstring change:

~~~sh
uv run --project python python python/scripts/generate_api_docs.py
uv run --project python python python/scripts/generate_teaching_traces.py
~~~
